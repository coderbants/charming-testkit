# Charming Testkit (`charming-testkit`)

**Charming Testkit** is a small support crate for the [Charming](https://github.com/coderbants) port family: helpers for driving and asserting against terminal applications under test (PTY sessions, key/mouse sequence builders, screen text predicates). It backs the interactive integration tests in the other Charming crates.

## Installation

Add it as a dev-dependency:

```sh
cargo add --dev charming-testkit
```
